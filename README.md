# Звіт з домашнього завдання: Обчислення визначеного інтеграла методом Монте-Карло

## Опис завдання

Було реалізовано програму для знаходження визначеного інтеграла функції `f(x) = x^2` на проміжку від `a=0` до `b=2` за допомогою методу Монте-Карло.

Програмно побудовано графік функції з виділенням області інтегрування, а також проведено чисельне інтегрування за допомогою функції `quad` з бібліотеки `scipy.integrate`.

## Результати

Аналітичний результат (функція `quad`):

Інтеграл: 2.666666666666667 2.960594732333751e-14

Результат методом Монте-Карло (100 експериментів, по 15000 точок):

Середня площа за 100 експериментів: 2.665831616099043

## Порівняння

Результати методу Монте-Карло близькі до аналітичного значення, відхилення знаходиться у межах статистичної похибки, що зменшується зі збільшенням кількості експериментів та кількості випадкових точок.

## Висновок

Метод Монте-Карло дозволяє отримати оцінку значення інтегралу з допустимою похибкою, яка залежить від кількості експериментів та кількості випадкових точок. Для більш точних результатів необхідно використовувати більше точок у симуляції.
